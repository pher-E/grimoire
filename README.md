# Clocktower Grimoire (v1.0.0)
The online grimoire for the hidden role game Blood on the Clocktower by The Pandemonium Institute, similar that which was once upkept at clocktower.online by Github user bra1n, which is no longer maintained. 

As it is currently written and being drafted, it is being made to run in the terminal, with potential plans to expand it into a website or application.
